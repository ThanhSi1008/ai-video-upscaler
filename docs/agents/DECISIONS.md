# Architectural Decision Records (ADR)

## Active ADRs

### ADR-001: 100% Local GPU Video Upscale & 100% Cloud Gemini Subtrans
- **Decision:** Run Video SR locally on NVIDIA CUDA/TensorRT 10.16 FP16 (`RTX 3060 12GB`); run subtitle translation strictly via Google Gemini Cloud API (3-key round-robin). Never load local LLMs (Ollama / TranslateGemma) when GPU upscaling or subtrans runs.
- **Rationale:** Concurrent local LLM loading exhausts 12GB VRAM and causes OOM crashes.

### ADR-002: Mandatory `-max_interleave_delta 0` for Stream-Copy MKV Mux
- **Decision:** Always mux with `-map 0:v:0 -map 1:a? -map 1:s? -map 1:t? -map_chapters 1 -c copy -max_interleave_delta 0`.
- **Rationale:** Prevents FFmpeg interleave skew across multi-channel audio (5.1/FLAC/TrueHD) and softsubs that triggers local audio dropouts on TV/media players.

### ADR-003: Two-Way ITU-R BT.709 Color Matrix & Mux VUI Gate
- **Decision:** Extract with `scale=in_color_matrix=bt709:in_range=tv:out_color_matrix=bt709:out_range=pc` (TV Limited -> RGB24 Full); encode with `pc -> tv` (`p010le`, plus `setparams=range=tv:colorspace=bt709:color_primaries=bt709:color_trc=bt709` on FFmpeg 8.x `scale` filtergraphs), tag `-color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709 -tag:v hvc1`, and enforce 10-bit + BT.709 `tv` VUI inside `verify_mux_integrity` (`video_vui_audit`).
- **Rationale:** Eliminates gamma wash-out, crushed blacks, and FFmpeg 8.x `scale` `unspecified` primaries/transfer resets on anime masters.

### ADR-004: Keyframe GOP + DIS Optical Flow Deduplication
- **Decision:** Split on source IDR keyframes (`split_video_segments`), force-keep chunk frame 0, scan 1-pass `mpdecimate` (`768:320:0.33` default) + optional early-exit DIS optical flow (`--dedup-policy dis`, `--dis-thresh 0.30`), and re-expand frames in NVENC/Concat Demuxer.
- **Rationale:** Anime limited animation contains ~55-62% duplicate frames; DIS preserves slow pans/zooms without full-frame inference cost.

### ADR-005: AnimeJaNai Residual Fix (`janai-fix`)
- **Decision:** Add `F.interpolate(x, scale_factor=2.0, mode='nearest')` residual skip in `AnimeJaNaiCompact2x` (`src/cuda_engine.py`).
- **Rationale:** Matches Spandrel CPU reference bit-exactly (PSNR 75-158 dB; prevents darkened/corrupted output).

### ADR-006: Whisper 5.1 FC Extraction & Hallucination Filtering
- **Decision:** For 5.1+ Japanese audio without JA subs, mix center speech (`pan=mono|c0=0.7*FC+0.15*FL+0.15*FR,highpass=f=80,lowpass=f=8000,afftdn=nf=-25`), transcribe with `faster-whisper` (`large-v3-turbo`) + Silero VAD, strip `WHISPER_HALLUCINATION_REGEX` / `SCREAM_OR_REPEAT_LOOP_REGEX`, and snap timestamps to studio EN via monotonic DTW (`subtrans/dtw_auto_align.py`).

### ADR-007: Multi-Speaker CC Splitting & Dual Dialogue Merging
- **Decision:** Split combined CC events (`-（Speaker1）...\N-（Speaker2）...`) in `subtrans/parser.py`, preserve `Cue.speaker`, translate independently, and merge simultaneous cues into 2-line Dual Dialogue (`- Line 1\n- Line 2`) in `subtrans/writer.py` with duplicate-variant suppression (`>= 15` common prefix chars or `>= 60%` token overlap).

### ADR-008: TensorRT 10.16 FP16 + NVENC `p6 CQ 18` + Episode-Locked Multipass (No INT8 PTQ / No Preset Downgrade)
- **Decision:** Use TensorRT 10.16 FP16 (`HMMA.16816.F16`, `builder_optimization_level=3`, 2-slot `_out_ring`) + CUDA P0 (`7500 MHz`) + HAGS (`HwSchMode=2`), paired with `hevc_nvenc` `main10`, `p010le`, `p6`, `CQ 18`, `rc-lookahead 32`, Dual AQ (`spatial-aq 1`, `aq-strength 6`, `temporal-aq 1`), and episode-locked `--nvenc-multipass auto|fullres|qres` (default `auto` per ADR-013: `fullres` for AI-bound `eff_ai_fps <= 24.0`, `qres` only when `eff_ai_fps > 24.0`).
- **Rationale:** `INT8 PTQ` causes `Q/DQ` reformat stalls and 8-bit banding across 33 `PReLU` layers; lowering `p6 -> p1` saves `0.0s` under AI-bound regimes while adding mosquito noise around black lineart, while `auto` preserves `fullres` on AI-bound runs and avoids NVENC bottlenecks above 24 fps.

### ADR-009: Zero-Disk 3-Stage Overlap, Cyclic Cel (`A->B->A`), & 1-Pass Concat-Mux
- **Decision:** Default `--zero-disk=True`: stream `NVDEC RGB24` via `readinto()` -> pinned `NHWC` -> Triton JIT `p010le` -> `hevc_nvenc` pipe with 3-stage overlap (`Decode N+1 || GPU N || Encode N-1`), `BLAKE2b` + SIMD `Cyclic Cel` memoization (Belady's OPT / NTFS `os.link`), `raw_actions_rle` `< 1 ms` GOP re-partitioning, 1-pass `mux_segments_directly`, and 1-pass `-f streamhash` MD5 audit.

### ADR-010: Reject Cross-Episode OP/ED Cache
- **Decision:** Never share/cache rendered 4K OP/ED video across episodes.
- **Rationale:** Staff/cast credits change in 100% of EDs and >70% of OPs (breaking bit-exact matching), GOP boundaries drift across cold opens (violating 1:1 `nb_frames`), audio overlaps OP/ED transitions, and net whole-season speedup is only ~1.7-2.2%.

### ADR-011: GA106 Silicon Ceiling, NVENC `fullres` Wall & E-Drive Isolation
- **Hardware Ceilings (RTX 3060 12GB `GA106-302-A1`, i5-12600K, 32GB DDR4-2133, WD_BLACK SN7100 NVMe):**
  - Isolated dense `cublasGemmEx(16F)` = `38.84 TFLOPS`; `cublasGemmEx(32F)` = `23.21 TFLOPS`; GDDR6 STREAM Triad = `302.61 GB/s`; PCIe 4.0 DMA = `22.81 GB/s` H2D / `22.64 GB/s` D2H; Triton input norm = `0.513 ms/batch` (`290.88 GB/s`); **7th-Gen NVENC 4K Main10 `-multipass fullres` steady wall = `22.70 fps` (`44.05 ms/frame`)**.
  - **3 Canonical Regimes (`Fate/Apocrypha Ep 22`, 1,478 frames, 95.06% unique):** `animevideov3` (`10.13 fps` E2E / `11.00 fps` TRT, 170W TGP bound) | `animejanai-hd-v3-sharp1-ultracompact` Native 2x (`18.52 fps` E2E / `22.83 fps` TRT, compute-NVENC knee) | `animejanai-hd-v3-sharp1-superultracompact` Native 2x (`20.80 fps` E2E / `44.91 fps` TRT, NVENC-bound).
  - **E-Drive Isolation (`src/env_isolation.py`):** Route Python 3.11.9 (`bin/python311/`), `.venv`, `bin/ffmpeg/`, `TEMP`/`TMP`/`TMPDIR` (`scratch/tmp`), and all HF/Torch/CUDA/Triton/Pip/Ruff caches (`E:\ai-video-upscaler\.cache/`) strictly onto E: drive.

### ADR-012: Antigravity-Exclusive Single-Context, AI-Native Comments & Tiered Context Harness
- **Decision:** Keep root instructions compact (`GEMINI.md <= 45` lines / `<= 4,500` bytes), enforce AI-only concise English comments/docstrings while preserving parser/test-coupled Vietnamese runtime logs and VI/JA domain data, allow free local `.env` reads (gating edits with `force_ask` and blocking Git/bundle/HTTP leaks), enforce context + full-overwrite firewalls (`upscaler-guard`), iterate via batched `agent_context.py --pack` / `--slice` / `--impact` and `verify_offline.py --target` / `--impacted`, auto-sync 6 fixed review bundles (`latest_diff.txt`, 4 prefix-cache-friendly domain `focus_*.txt`, and deduplicated unnumbered `focus_full.txt`) via `post-commit` (`export_review_bundle.py --sync-latest`), and require same-commit doc-sync across affected docs.

### ADR-013: Pareto Visual-Quality & E2E Speed Architecture (`O1`–`O6`)
- **Decision:**
  1. **`O1` Analytical Catmull-Rom 4x->2x Collapse (`B=0.0, C=0.5`):** Collapse `SRVGGNetCompact` `PixelShuffle(4) + Nearest(4x) + AA Bicubic(0.5x)` into 1080p `Conv2d(48->12, 3x3, groups=3) + Conv2d(3->12, 3x3, groups=3) + PixelShuffle(2)` (`Slice+Concat` replicate border, `_aa2x` TRT cache tag; generic 4x Spandrel falls back to 2-frame-sliced `antialias=True`).
  2. **`O2` 10-Bit End-to-End Semi-Planar Pipe:** Decode native `p010le` / `nv12` in Zero-Disk mode, convert via `@triton.jit` `_yuv420_to_nchw_fp16_bt709_kernel` (`left` chroma) and `_rgb_to_p010le_triton_kernel` (`left` `[1,2,1]/4 x [1,1]/2` chroma + spatial IGN `±0.499 LSB` dither), normalize `p010le` MSBs for cyclic dedup, and cap `memo_p010 <= 64` frames.
  3. **`O3` & `O6` `24s` Super-Chunks, Bounded Rolling Preflight & Episode-Locked NVENC:** Auto-promote omitted `-s` to `24s` in CUDA Zero-Disk mode, bound `RollingDedupPlanner` to `max_workers=2` (`sync_initial_chunks=3` warmup before `finalize_plan` locks `episode_multipass`, `-threads 2`, Open-GOP RASL `_count_leading_discard_packets` + `_recover_open_gop_leading_frames` reconciliation) to protect `DDR4-2133` bandwidth, run in-process PyAV `hevc_nvenc` (`stream.bit_rate = 0`, `chroma_location="left"`, monotonic `AVFrame` allocation), propagate `episode_multipass` identically to `open_chunk_encoder`/`encode_chunk_reexpanded`/`encode_chunk_hevc`, and lock `--nvenc-multipass auto|fullres|qres` **per-episode** so `-f concat -c copy` never mixes mismatched HEVC VPS/SPS/PPS `extradata`.
  4. **`O4` & `O5` Perceptual Dedup V2 (`dis-auto`, `sakuga`) & Same-Family Routing:** Use `8x8` dual-phase lip-flap cells (`32x32` at 1080p) + 3-DOF textured Lucas-Kanade + noise-calibrated DIS (persisting `dis_thresh` across all DIS policies including `sakuga`/`dis-sakuga`); keep `shows.yaml` mapped to single consistent models per episode (`sharp1-ultracompact` BD, `ultracompact` Web-DL, `animevideov3` fallback) and offer explicit `--model auto-pareto` (`compact` 16c + `ultracompact` 8c, scene-cut hysteresis).

### ADR-014: Lazy `src/config.py`, Strict TRT `.sha256` Verification & Scheduler/Retry Safety
- **Decision:** Resolve `DEFAULT_ENGINE`, `DEVICE_NAME`, `DEFAULT_BATCH_SIZE`, and `HEVC_ENCODER` lazily via PEP 562 `__getattr__` + `@lru_cache` in `src/config.py` (`< 80 ms` cold import without eager `torch`/`ffmpeg -encoders`), gate `_atexit_release_gpu_lock` on `_GPU_LOCK_OWNED` / `_GPU_LOCK_DEPTH` + `is_gpu_lock_held_by_other()`, require valid `.sha256` sidecars in `verify_trt_engine_sha256_sidecar` (never retroactively stamping unverified engines) + `torch.load(..., weights_only=True)`, reject mismatched `dedup_policy` in `find_cached_plan`, enforce `1.0` keep factor for `"off"` in `check_deadline_and_eta`, forward `eff_segment_time`/`nvenc_multipass`/`segment_time_explicit` on retries, and `break` cleanly under `--allow-partial` without `+1 day` wrap. Defer live GPU `build_trt_engine.py` 96-frame `.engine` benchmarking behind `GEMINI.md` §4 user approval.
- **Rationale:** Prevents slow cold imports in CLI/scheduler/test paths, blocks unverified serialized TensorRT/PyTorch artifacts, and eliminates silent retry/deadline/policy drift.

In Web Studio, enforce strict JSON (`NaN`/`Inf` -> `None`, `allow_nan=False`), O(1) `_poll_tick_sync`, `/api/audits` 1.5s stat-guarded TTL cache, `.env` key priority parity, `--mock` zero-disk idempotency, `web_job_<id>.log` (`N=20`) retention, `scratch/web_compare/*.png` `_lifespan` cleanup, and Win11 P-core QoS + `OMP=1` calibrated 6-shard `verify_offline.py`. Enforce `src.logger` exclusion from `web/` and stdlib-only `src/night_report.py` (`workspace_root` isolation + `GET /api/night-report`), propagate `UPSCALER_WEB_JOB_ID` + `ppid` for Windows `.venv` PID lineage (`live_matches_web_job`), clean descendant `.gpu_active.lock` owners on `abort_job`, isolate `UPSCALER_LOGS_DIR` in `tests/conftest.py`, isolate `.preview_clip_*` in target `-o` dirs with PyAV `preview_start_sec` matching, persist LF line endings on config writes, and deduplicate paired `_4K` audits. In post-abort teardown (`M6`), finalize `"aborted"` jobs deterministically in `JobManager.abort_job()`, `get_state()`, and `_spawn_command()` with strictly idempotent `_finalize_locked()`, fall back to unfinalized `"aborted"` `active_job` (by `job_id`) in `TelemetryHub._resolve_last_job()` so `effective_stage` stays `"paused"` without dropping chunk telemetry, serialize `.graceful_pause.flag` atomic write (`pid.tid.uuid8.tmp` + `os.replace`) and `unlink` inside `JobManager._lock` (clearing `.graceful_pause.flag` on `"aborted"` transition, refusing flag creation when `active_job.status == "aborted"` unless finalized with a live external CLI active via `.gpu_active.lock` or non-matching active-stage `live_status.json`, and preserving external-CLI pause compatibility when `active_job is None` or non-aborted), return HTTP `409` from `POST /api/jobs/pause-graceful` whenever `ok` is `False`, and guard `res.ok === false` / `409` in `web/static/js/app.js` with `"warn"` toast instead of a false-positive confirmation.
- **Rationale:** Achieves `< 300 ms` offset detection, `< 35 MB` DTW RAM, `< 3 ms` `/api/audits` p50, zero live API/cache leaks, and `~34s` 6-shard offline verification without altering any of the six frozen subsystem cores.
